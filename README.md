# Programmable Laser Driver
A programmable laser driver board with computer interface based on TM4C123G ARM-Cortex M4F microcontroller and LTC2662 16-bit Current-Output Digital to Analog Converter. This board is for educational and training purposes, suitable for low cost lab instruments for physics and optics experiments, optogenetics proof of concept, and programmable electrical current source.     
Tiva C Connected Launchpad board from Texas Instruments can be used to program the onboard TM4C123G microcontroller.
